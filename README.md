# NA-HE & NA-HD CODE

**Efficient Constant-Time Complexity Hilbert Curve Encoding and Decoding Algorithms and its Application in Image Representation**

We propose novel Neighbor-aware Hilbert Encoding (NA-HE) and Decoding (NA-HD) algorithms, the first to systematically exploit inter-point relationships to accelerate Hilbert curve operations. Our approach leverages a 3-point model and dynamic state updates to minimize redundant iterations, reducing the average per-point time complexity from O(k) to O(1), where k is the level of Hilbert space.

**Environment**
- System: Windows
- Language: C++
